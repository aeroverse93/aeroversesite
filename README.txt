# AeroVerse Website

A beginner-friendly, responsive aviation website built with plain HTML, CSS and JavaScript.

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html` to open it in your browser.

## Publish for free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `aeroversesite`.
3. Upload the three website files.
4. Open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select your main branch and `/ (root)`, then Save.
7. GitHub will provide your live website address.

## Customize
- Change the site title and text in `index.html`.
- Change colors, spacing and layout in `style.css`.
- Add new sections or interactive features in `script.js`.
